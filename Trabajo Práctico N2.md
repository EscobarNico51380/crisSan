**Trabajo Práctico N°2 – Sistemas Inteligentes con RAG o Agentes**  
**Tipo de trabajo:** Práctico con defensa oral  
**Entregable:** Notebook interactivo \+ Presentación oral

**📌 Contexto General**

En este segundo trabajo práctico, se busca que los estudiantes apliquen de manera integrada los conceptos avanzados abordados durante la cursada: RAG (Retrieval-Augmented Generation), agentes inteligentes, embeddings, NLP y el uso de modelos de lenguaje de gran escala (LLMs), utilizando herramientas como **Langchain** y **APIs de modelos como ChatGPT o LLaMA**.

El objetivo es diseñar y construir un **sistema experto funcional** que resuelva un problema real o simulado dentro de un **caso de negocio elegido por el equipo**. Se espera que el sistema sea capaz de tomar decisiones, recuperar información relevante, interactuar en lenguaje natural y demostrar inteligencia contextual.

**🎯 Objetivos**

* Aplicar conceptos de IA avanzada en el desarrollo de un sistema experto.  
* Diseñar una solución completa basada en **RAG** o **agentes inteligentes**.  
* Utilizar herramientas vistas en clase: **Langchain**, embeddings, modelos LLM, etc.  
* Integrar una API externa (ChatGPT) o correr un modelo local (LLaMA).  
* Identificar y documentar los desafíos técnicos y decisiones de diseño.  
* Comunicar de forma clara el funcionamiento del sistema y su aplicación práctica.

**🛠️ Requisitos Técnicos**

* El sistema debe estar construido usando **Langchain** como framework principal.  
* Puede estar basado en:  
  * Un **agente inteligente** que actúe sobre múltiples herramientas (search, APIs, bases de datos, etc.).  
  * Un sistema de **RAG** que permita enriquecer respuestas mediante recuperación de información.  
* El modelo de lenguaje puede ser:  
  * **GPT (vía API de OpenAI)**  
  * **LLaMA (local o API alternativa)**  
  * **Otros modelos no vistos en clase**  
* De ser necesario usarse **embedding de texto** para representar documentos o consultas.  
* La lógica del sistema debe estar documentada y ser reproducible en un **notebook interactivo**.

**🧪 Criterios de Evaluación**

| Criterio | Descripción |
| ----- | ----- |
| **Funcionamiento del sistema** | Que el sistema funcione correctamente con casos de prueba. |
| **Aplicación del marco teórico** | Que utilice adecuadamente conceptos como RAG, agentes, NLP, embeddings. |
| **Creatividad y originalidad** | Valoración del caso de negocio y la solución propuesta. |
| **Documentación técnica** | Claridad en el código, explicaciones y decisiones tomadas. |
| **Identificación de dificultades** | Capacidad de explicar errores, problemas y cómo fueron resueltos. |
| **Presentación y defensa** | Calidad de la presentación, dominio del tema, respuestas en la defensa. |

&nbsp;

**🧾 Entregables**

1. **Notebook interactivo** con el sistema desarrollado, código y comentarios.  
2. **Presentación (oral)** del proyecto con una defensa de:  
   * El caso de negocio elegido.  
   * Cómo fue resuelto con IA.  
   * Qué decisiones se tomaron y por qué.  
   * Qué dificultades encontraron.  
   * Qué resultados obtuvieron.
